# CFG→NET — Cisco Config ネットワーク図ジェネレーター

Ciscoの `show running-config` を貼り付けるだけで、ネットワーク構成図(論理図・物理図)と機器/VLAN/IPの一覧表を自動生成するツールです。**単一のHTMLファイル**で動作し、インストール・サーバ・外部通信は一切不要。ブラウザで開くだけで使えます。

> 社内のネットワーク保守業務で「コンフィグはあるが最新の構成図がない」案件向けに開発。100台規模の実環境データで検証済みです。

## 特徴

- **コンフィグ貼り付けで機器を自動解析** — `hostname` 行で複数台を自動分割。インターフェース、VLAN、SVI/IPアドレス、VRRP/HSRP、Port-channel、スタック構成、STP、ルーティング方式(Static/EIGRP/OSPF/BGP/RIP)、ACL数を抽出
- **接続の自動推定** — インターフェースのdescriptionから対向機器・ポートを検出してリンクを自動生成。`show cdp neighbors detail` の貼り付けにも対応
- **論理図/物理図/一覧表の3ビュー** — 物理図は設置場所(フロア・ラック等)ごとにグループ枠表示。一覧表はVLAN・機器・IPアドレスをCSV出力可能(BOM付きUTF-8、Excel対応)
- **ケーブル種別の可視化** — 光ファイバ/UTP/DACを色・線種で区別。`show interface status` のType列(1000BaseSX等)から実装ベースで判定を更新可能
- **PNG/SVG出力** — PowerPointにそのまま貼れる白背景PNG(2倍解像度)と、拡大しても劣化しないSVG
- **編集機能一式** — 複数選択ドラッグ、整列(揃え/等間隔)、Ctrl+Zアンドゥ、吹き出しコメント、塗りつぶし色、機器種別ごとの形状(サーバ/FW/無線AP/IP電話/WANクラウド等)
- **データ保持** — ファイル名を付けたJSON保存/読込に加え、localStorageへの自動保存でブラウザ不意終了からも復元

## クイックスタート

1. `network-diagram.html` をダウンロードしてブラウザで開く(Chrome/Edge推奨)
2. **「サンプル読込」** を押してデモ構成を確認
3. 自分の環境で使うときは **「新規」** → 機器タブに `show run` を貼り付けて **「解析して追加」**

ビルド不要・依存ライブラリなし。HTMLファイル1つで完結します。

## 使い方

### 1. コンフィグの取り込み

機器タブのテキストエリアに `show running-config` を貼り付けます。複数台まとめて貼り付けても `hostname` 行で自動分割されます。同じhostnameを再投入すると機器が**上書き更新**され、配置・色・設置場所などの編集内容は維持されます。

### 2. 接続(リンク)の自動推定

descriptionに対向の機器名とポートが書かれていれば自動でリンクが張られます。

```
interface GigabitEthernet1/0/49
 description *** To:CORE-SW1 Gi1/0/3 ***
```

推定エンジンは実環境のdescription運用に合わせて次の対応をしています。

| 状況 | 動作 |
|---|---|
| 略記ゆれ | `Gi` `GigabitEthernet` `G` `giga` `gigabit` `GE` `Te` `T` `Fa` `F` など主要な表記に対応 |
| スタック番号の省略 | desc記載 `G0/27` を実在ポート `Gi1/0/27` に自動正規化 |
| メンバーポートのdesc誤記 | Port-channelのdescriptionが正しければ、Poメンバー同士を番号順に対応付けて救済 |
| descの陳腐化・矛盾 | 「相互に指し合うペアを優先」「1ポート1ケーブル」制約で、古いdescによるゴーストリンクを排除 |
| ホスト名の誤記 | 接続タブの**未解決レポート**に編集距離2以内の類似候補を表示、ワンクリックで接続可能 |

自動推定で拾えない接続は、接続タブで手動追加・編集(機器/ポート/ケーブル種別)できます。

### 3. ケーブル種別(光/UTP)の精緻化

インターフェース名からの初期判定(Te系=光、Gi系=UTP)に加え、機器タブに `show interface status` を貼り付けるとType列から実装ベースで更新します(`1000BaseSX/LH`→光、`10/100/1000-TX`→UTP、`No Gbic/No XCVR`→SFPスロット=光、DAC/Twinax→DAC)。プロンプト行(`HOSTNAME#show interface status`)を含めれば複数機器分を一括取り込みできます。4506等のシャーシ型でGiポートに銅/光が混在する構成に有効です。

### 4. 物理図と設置場所

機器の詳細タブ、または複数選択時の一括設定パネルで設置場所(例: `本社3F サーバ室 Rack-A`)を指定すると、物理図で場所ごとの点線枠にグルーピングされます。既存の場所名は入力候補に出るため表記ゆれを防げます。「論理→物理 配置コピー」で論理図のレイアウトを物理図に反映できます。

### 5. Cisco以外の機器・サーバ

機器タブの「オブジェクト追加」から、サーバ/FW/ロードバランサ/無線AP/ストレージ/UPS/プリンタ/PC/IP電話/WAN回線などを手動追加できます。種別ごとに形状が変わり(サーバ=ラックマウント風、AP=電波アーク付き、WAN=雲形など)、descriptionに名前が書かれていれば自動推定の対象にもなります。Cisco機器側も「表示種別」で形状を変更可能です(例: SAP1602を無線AP表示にする)。

### 6. 出力

| 形式 | 用途 |
|---|---|
| PNG | PowerPoint貼り付け用。白背景・2倍解像度。巨大図はcanvas上限(16,000px)内に自動調整 |
| SVG | ベクター形式。PowerPointに直接挿入でき、拡大しても劣化しない。大規模図はこちら推奨 |
| CSV | 一覧表(VLAN/機器/IPアドレス)を表ごとに出力。BOM付きUTF-8で日本語Excel対応 |
| JSON | プロジェクトの保存/読込。ファイル名がPNG/SVGのファイル名にも使われる |

VLAN絞り込み・機器名検索で減光した状態はそのまま画像出力に反映されるため、「VLAN別」「拠点別」の抜粋図が簡単に作れます。

## キーボード・マウス操作

| 操作 | 動作 |
|---|---|
| 背景をドラッグ | 矩形範囲選択 |
| Shift + クリック | 選択に追加/除外 |
| Ctrl/⌘ + A | 表示中ビューの全選択 |
| 選択中をドラッグ | まとめて移動 |
| Ctrl/⌘ + Z / Ctrl+Y | 元に戻す / やり直す(履歴60ステップ) |
| Ctrl + ホイール | ポインタ位置を中心にズーム |
| Esc | 選択解除 |

整列ボタン(⇤⇥⤒⤓↔↕)で左右上下揃え・等間隔配置ができます。

## 解析対応項目

hostname / interface(description, switchport mode/access/trunk allowed/native, channel-group, media-type, ip address, shutdown, encapsulation dot1Q, VRRP/HSRP) / vlan定義 / SVI / spanning-tree mode・priority / ip routing / ip route / router eigrp・ospf・bgp・rip / access-list(番号・名前付き) / switch provision(スタック) / show cdp neighbors detail / show interface status

## データの保存について

- 編集内容は約0.8秒間隔でブラウザのlocalStorageに自動保存され、次回同じファイルを開くと復元されます
- localStorageは「ブラウザ×ファイルの場所」単位です。HTMLの移動や別ブラウザでは引き継がれないため、**案件の区切りではJSON保存を正**としてください
- JSON読込時は過去バージョンのデータ互換を維持し、ID重複などの既知の問題を自動修復します

## 制限事項

- 接続推定はdescription/CDPの記載品質に依存します。記載がない接続は手動追加が必要です
- STPルートは `spanning-tree vlan X priority` の設定値からの推定です。全機器デフォルト値の環境では表示されません(実際のルートはMACアドレスで決まるため)
- VLANフィルタの判定において、`show run` にはVTP配布のVLANデータベースが含まれないため、allowed未指定トランクは「明示的な根拠が片端にある場合のみ通過」として扱います
- 対応OSはCisco IOS/IOS-XE系の構文です

## 技術構成

Vanilla JavaScript + SVG によるシングルファイルHTML(依存ライブラリなし、ビルド不要)。描画は差分更新方式で、100台/300リンク超の構成でもドラッグ操作が軽快に動作します。開発時はjsdomによる自動テスト(150項目超)で回帰を検証しています。
